# hongguo-web

红果短剧的自研 web 前端，个人自用。

官方的 `hongguo-desktop-companion.exe` 只支持 Windows 且闭源。这个项目用浏览器把它替掉：在局域网里跑一台电脑当服务端，手机 / 平板 / 电视打开网页就能看，没有广告，也不用给每台设备单独装东西。

## 功能

- **免配置**：第一次打开时在本地生成一把 api_key，服务端会登记它。不用先跑去后台开密钥、再手工填进来
- **播放器**：桌面端是固定舞台加右侧选集面板；手机端一屏一集，上下滑动切换，靠 `scroll-snap` 加 `IntersectionObserver` 对齐当前集。桌面端的 `<video>` 跨集复用、只换 `src`，所以画中画窗口在自动跳集时不会断
- **默认带声音**：浏览器只放行"用户已经跟页面交互过"的带声音自动播放。被拦下来时先静音把画面放起来，右下角给一个提示，碰一下就把声音补上
- **控制条**：倍速、音量、亮度、全屏、画中画、可拖动的进度条。手机屏幕窄，音量亮度和倍速收进设置面板，控制条只留播放、进度和时间
- **探索**：按主题 / 设定 / 背景 / 受众 / 上架时间等多维筛选，首屏取 100 部，点「加载更多」继续往下翻
- **搜索**：真人剧和动漫剧是两个独立的片库，同名剧在两边是两部完全不同的剧（《万妖图录传》在两边各有一部，`series_id` 不同）。所以搜索框下面有个显式的类型切换，而不是替你猜
- **其他季**：一部剧的季在上游是各自独立的条目，搜索时是散着的。详情页把它们横排成一条「其他季」，认准当前这部剧所属的片库再挑，同名的那部不会串进来
- **详情页**：演员表（头像 / 姓名 / 角色），以及分段的数字选集宫格 —— 几百集的剧切成每 30 集一段，比一条横向长条好找
- **下一集预加载**：进当前集时给下一集发一个 `Range` 探针，触发服务端提前解密，切集时不用等
- **PWA**：可以加到手机主屏。从图标启动时全屏运行，底部导航栏能贴到屏幕底，不会被浏览器工具栏顶上去

## 运行

前端只是静态产物，需要配套的后端接口才能工作。

```bash
pnpm install
pnpm dev      # 开发服务器, 5173, /hgapi 代理到后端 8000
pnpm build    # 产物落在 dist/
```

接口地址通过 `VITE_API_BASE` 配置，见 `.env.development`。

## 技术栈

Vite 8 + React 19 + TypeScript 6，服务端状态交给 TanStack Query。样式是原生 CSS 加一套设计令牌，没有引 UI 框架。

## 已知限制

- 依赖本机的后端服务，没有做多用户隔离，只适合放在内网
- 源视频是 HEVC（H.265）。Safari 和装了 HEVC 扩展的 Windows 浏览器能直接播；Linux 上的 Chrome / Firefox 没有系统解码器，需要后端转码成 H.264
- 横屏的漫剧在竖屏手机上会留黑边，目前用模糊背景缓解，没有做裁切
